# noupdateever.

Software that never changes out from under you.

This is the home of **Stasis** (working name) — an update firewall: a single
sealed binary that stops every application on a machine from updating
itself, and turns change into something that happens only when you open the
gate — deliberately, visibly, reversibly.

Built in our style: everything is decided upfront, the spec is the contract,
and when the software matches the spec, the product is *finished* — sealed
forever. No auto-updates. No telemetry. No login. No feature ever removed.

## The idea in three lines

1. People don't hate updates — they hate **change they didn't choose**.
2. People already pay serious money for stasis (Microsoft ESU, Deep Freeze,
   used XP machines for factories).
3. So we sell stasis itself: a sealed-forever engine, with the world's churn
   quarantined into replaceable, signed **recipe** data files.
